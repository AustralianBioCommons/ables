## Project title

Fruit fly metabarcoding for biosecurity

## Collaborators and funding

[Free and Secure Trade Alliance](https://www.dpi.qld.gov.au/business-priorities/agriculture/initiatives/fresh-and-secure-trade-alliance)

## Contact(s)

- IElizabeth Fowler, QDPI,<Elizabeth.Fowler@dpi.qld.gov.au>

## Project description and aims

This project aims to produce a system where metabarcoding is used instead of onerous morphological identification. Planned analyses include the following approaches: genomic sequencing, CNV and SNP analyses, species classification by high-throughput sequencing against custom databases (metabarcoding). 

## How is ABLeS supporting this work?

This work is supported through the Production Bioinformatics scheme provided by ABLeS.

## Expected outputs enabled by participation in ABLeS

A seamless workflow where a user can upload read files and get a determination of the species present in a trap. These workflows would be available for others to use and customise for biosecurity or environmental monitoring. The workflow will be built with Nextflow and will be shared.
